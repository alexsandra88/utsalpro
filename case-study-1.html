Studi Kasus: Implementasi Bubble Sort dalam C++

5 Oktober 2026  •  Admin  •  Sorting

Bubble Sort adalah salah satu algoritma pengurutan yang paling sederhana. Algoritma ini bekerja dengan cara menukar elemen yang berdekatan secara berulang jika mereka berada dalam urutan yang salah.

Studi Kasus

Bayangkan kita memiliki kumpulan nilai ujian mahasiswa yang belum terurut. Kita diminta untuk membuat program yang dapat mengurutkan nilai-nilai tersebut dari yang terkecil hingga terbesar.

Contoh Input: 64, 34, 25, 12, 22, 11, 90
Output yang Diharapkan: 11, 12, 22, 25, 34, 64, 90

Implementasi C++

Berikut adalah kode C++ untuk menyelesaikan studi kasus di atas:

#include <iostream>
using namespace std;

// Fungsi untuk melakukan bubble sort
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        // Elemen terakhir i sudah berada di tempat yang benar
        for (int j = 0; j < n - i - 1; j++) {
            // Tukar jika elemen yang ditemukan lebih besar
            // dari elemen berikutnya
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

// Fungsi untuk mencetak array
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++)
        cout << arr[i] << " ";
    cout << endl;
}

int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    cout << "Array sebelum diurutkan: \n";
    printArray(arr, n);
    
    bubbleSort(arr, n);
    
    cout << "\nArray setelah diurutkan: \n";
    printArray(arr, n);
    return 0;
}

Analisis Kompleksitas

  • Time Complexity: O(N2) pada kasus terburuk dan rata-rata, dimana N adalah jumlah item yang diurutkan. O(N) jika array sudah terurut (dengan optimasi flag).
  • Space Complexity: O(1) karena hanya menggunakan variabel temporary tambahan.
