2. Refleksi Pembelajaran & Evaluasi Teknis

Bagian Tersulit yang Dihadapi

Bagian tersulit adalah menghitung nilai tertinggi, terendah, dan rata-rata kelas tanpa menggunakan struktur data array (sesuai batasan proyek E.4). Kami harus merancang algoritma akumulator berjalan yang menginisialisasi patokan awal pada mahasiswa pertama (totalMahasiswa == 1) dan secara dinamis memperbarui nilai ekstrem setiap kali ada data baru. Selain itu, membersihkan buffer input (stream clearing) saat menangani input non-numerik memerlukan pemahaman mendalam tentang cin.clear() dan cin.ignore().

Pengetahuan yang Diperoleh

Kami memahami secara mendalam hubungan keterikatan antara problem understanding, flowchart, pseudocode, hingga implementasi kode program. Kami belajar bagaimana mengevaluasi kondisi logika majemuk (menggunakan operator &&) untuk multi-syarat kelulusan, teknik validasi masukan defensif agar aplikasi tidak crash, serta koordinasi Git/GitHub untuk kolaborasi tim yang terdokumentasi rapi.

Rencana Pengembangan untuk UAS

Untuk proyek tingkat lanjut pada Ujian Akhir Semester (UAS), sistem pengolahan nilai ini dapat dikembangkan lebih lanjut dengan:

  • Penerapan Struktur Data Dinamis / Array of Struct: Memungkinkan data seluruh mahasiswa disimpan di memori dan dapat diedit kembali jika terjadi salah ketik sebelum finalisasi.
  • Penyimpanan Persisten (File Handling / Database): Menyimpan data ke file teks/CSV sehingga nilai semester dapat dimuat kembali setelah program ditutup.
  • Modularisasi Fungsi / Prosedur: Memecah perhitungan ke fungsi-fungsi terpisah agar kode semakin rapi dan mudah di-maintain.
  • Antarmuka Grafis (GUI) / Web Dashboard: Mengembangkan visualisasi grafik batang untuk sebaran nilai A-E.
