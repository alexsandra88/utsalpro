Analisis Masalah & Input-Process-Output (IPO)

Pemodelan komprehensif permasalahan pengolahan nilai mata kuliah, penentuan batasan, variabel, dan tipe data.

1. Latar Belakang & Rumusan Masalah

Dalam dunia pendidikan tinggi, evaluasi hasil belajar mahasiswa merupakan kegiatan krusial yang menuntut akurasi tinggi, objektivitas, dan kecepatan. Pada proses konvensional, perhitungan manual nilai akhir yang melibatkan persentase berbobot, pengelompokan huruf mutu, serta evaluasi kelulusan multi-kriteria sering kali rentan terhadap kesalahan manusia (human error).

Pada Studi Kasus 03: Sistem Pengolahan Nilai Mata Kuliah, dosen memerlukan program otomasi berbasis konsol/terminal C++ yang mampu mengolah data beberapa mahasiswa sekaligus secara konsisten. Sistem tidak hanya mengkalkulasi nilai individual secara adil, tetapi juga menyusun rekapitulasi performa kelas sebagai bahan evaluasi proses pembelajaran.

Rumusan Masalah Utama:
  1. Bagaimana mengimplementasikan perhitungan nilai akhir berbobot secara tepat (Tugas 20%, Kuis 15%, UTS 30%, UAS 35%)?
  2. Bagaimana mengkategorikan huruf mutu secara otomatis ke dalam rentang A hingga E?
  3. Bagaimana memvalidasi syarat kelulusan majemuk (Nilai Akhir ≥ 60, Nilai UAS ≥ 50, dan Kehadiran ≥ 75%)?
  4. Bagaimana melakukan agregasi statistik performa kelas (rata-rata, nilai tertinggi/terendah, rasio lulus) tanpa menggunakan array?

2. Tujuan dan Pengguna Program

Tujuan Pengembangan Program
  • Membangun sistem otomasi penilaian yang cepat, presisi, dan transparan.
  • Mencegah kesalahan perhitungan nilai akhir dan subjektivitas penentuan kategori.
  • Menyediakan rekapitulasi kelas komprehensif bagi dosen pengampu untuk pelaporan mutu perkuliahan.
  • Menerapkan prinsip algoritma terstruktur: percabangan majemuk, validasi ketat, dan perulangan.
Sasaran Pengguna (Target User)
  • Dosen Pengampu Mata Kuliah: Menginput komponen nilai mahasiswa secara cepat serta memantau daya serap kelas secara langsung.
  • Asisten Dosen / Administrasi Akademik: Membantu verifikasi data kehadiran dan komponen nilai sebelum finalisasi nilai semester.

3. Ketentuan dan Batasan Proyek

Ketentuan Logika Bisnis:
  • Bobot Komponen: Tugas 20%, Kuis 15%, UTS 30%, UAS 35%.
  • Skala Nilai Huruf: A (85-100), B+ (80-84.99), B (75-79.99), C+ (70-74.99), C (60-69.99), D (50-59.99), E (<50).
  • Syarat Kelulusan Simultan: Mahasiswa wajib memenuhi (NA ≥ 60.00) AND (UAS ≥ 50.00) AND (Kehadiran ≥ 75.00%).
Batasan Teknis (Sesuai Panduan UTS):
  • Program dijalankan berbasis Console / Terminal C++ murni.
  • Tanpa Array: Pemrosesan data berulang dilakukan dengan variabel akumulator berjalan.
  • Validasi Input: Nilai negatif (< 0) atau > 100 ditolak secara logis dan diminta input ulang.
  • Kekebalan Input (Anti-Crash): Input non-numerik ditangani dengan cin.clear() dan cin.ignore().

4. Analisis Input-Process-Output (IPO)

Data Masukan (Input) Proses Algoritmik (Process) Informasi Keluaran (Output)

Setiap Mahasiswa:

  • Nama Mahasiswa (String)
  • NIM Mahasiswa (String)
  • Nilai Tugas (Double, 0-100)
  • Nilai Kuis (Double, 0-100)
  • Nilai UTS (Double, 0-100)
  • Nilai UAS (Double, 0-100)
  • Persentase Kehadiran (Double, 0-100%)

Kontrol Alur:

  • Pilihan Pengulangan (Char 'y'/'t')
  1. Validasi: Memeriksa keabsahan rentang 0-100 untuk semua nilai & kehadiran. Mengulang input jika tidak valid.
  2. Perhitungan Nilai Akhir: NA = (Tugas*0.20) + (Kuis*0.15) + (UTS*0.30) + (UAS*0.35)
  3. Penentuan Kategori: Percabangan bertingkat (if-else ladder) untuk menentukan A, B+, B, C+, C, D, E.
  4. Pemeriksaan Multi-Syarat Kelulusan: Mengevaluasi kondisi logika majemuk NA ≥ 60 && UAS ≥ 50 && Hadir ≥ 75.
  5. Akumulasi Rekapitulasi: Menambahkan nilai ke total sum, mencatat frekuensi kategori, serta membandingkan nilai tertinggi dan terendah.
  6. Kalkulasi Agregat: Menghitung rata-rata kelas dan persentase kelulusan.

Laporan Individual:

  • Rincian nilai mentah & kontribusi bobot per komponen
  • Nilai Akhir presisi 2 desimal
  • Kategori Nilai Huruf
  • Status (LULUS / TIDAK LULUS) beserta catatan

Rekapitulasi Kelas:

  • Total mahasiswa diproses
  • Jumlah lulus & tidak lulus
  • Frekuensi tiap kategori A s.d. E
  • Nilai rata-rata kelas
  • Nilai tertinggi & terendah (beserta nama)
  • Persentase rasio kelulusan
