2. Analisis Masalah & Ketentuan Modul A

Dosen membutuhkan sistem otomatis berbasis konsol untuk mengolah data nilai mahasiswa. Modul A bertanggung jawab memproses setiap data individu secara terperinci sebelum diteruskan ke rekapitulasi Modul B.

Ketentuan Perhitungan & Aturan Bisnis:
Komposisi Bobot Nilai:
  • Nilai Tugas: 20% (0.20)
  • Nilai Kuis: 15% (0.15)
  • Nilai UTS: 30% (0.30)
  • Nilai UAS: 35% (0.35)
Syarat Kelulusan (Multi-Kriteria):

Mahasiswa dinyatakan LULUS jika dan hanya jika ketiga syarat berikut terpenuhi:

  1. Nilai Akhir ≥ 60.00
  2. Nilai UAS ≥ 50.00
  3. Persentase Kehadiran ≥ 75.00%

*Jika salah satu syarat gagal, otomatis TIDAK LULUS.

Skala Kategori Huruf Mutu:

80.00 - 84.99B+Baik Sekali

70.00 - 74.99C+Cukup Baik
60.00 - 69.99CCukup (Batas Minimal Kelulusan Nilai)
50.00 - 59.99DKurang

3. Analisis Input-Process-Output (IPO)

Input (Masukan) Process (Pemrosesan) Output (Keluaran)
  • namaMahasiswa (Teks)
  • nimMahasiswa (Teks)
  • nilaiTugas (Numerik, 0 - 100)
  • nilaiKuis (Numerik, 0 - 100)
  • nilaiUTS (Numerik, 0 - 100)
  • nilaiUAS (Numerik, 0 - 100)
  • persentaseKehadiran (Numerik, 0 - 100%)
  • pilihanUlang ('y' / 't')
  1. Validasi Input: Memeriksa apakah nilai berada di rentang 0 - 100 dan bukan karakter non-numerik. Jika salah, loop pengulangan input dilakukan.
  2. Perhitungan Kontribusi Berbobot:
    • Tugas = nilaiTugas * 0.20
    • Kuis = nilaiKuis * 0.15
    • UTS = nilaiUTS * 0.30
    • UAS = nilaiUAS * 0.35
  3. Kalkulasi Nilai Akhir:
    Nilai Akhir = Tugas + Kuis + UTS + UAS
  4. Percabangan Kategori: Mengevaluasi rentang nilai akhir dari A hingga E.
  5. Evaluasi Kelulusan: Cek kondisi majemuk (Nilai Akhir ≥ 60 AND Nilai UAS ≥ 50 AND Kehadiran ≥ 75).
  • Nama & NIM Mahasiswa
  • Rincian nilai mentah & kontribusi berbobot setiap komponen
  • Persentase kehadiran
  • Nilai Akhir (presisi 2 desimal)
  • Kategori Nilai Huruf (A - E)
  • Status Kelulusan (LULUS / TIDAK LULUS)
  • Catatan rincian penyebab jika tidak lulus

5. Algoritma Deskriptif

  1. Mulai Program: Menampilkan judul aplikasi pengolahan nilai mata kuliah.
  2. Inisialisasi Perulangan: Memulai blok perulangan do-while untuk mengolah data mahasiswa secara berulang.
  3. Input Identitas: Membaca masukan nama lengkap mahasiswa dan NIM.
  4. Input & Validasi Nilai Tugas:
    • Membaca nilai tugas.
    • Jika nilai bukan angka atau nilainya di luar rentang 0 s.d. 100, tampilkan pesan galat dan ulangi input nilai tugas hingga valid.
  5. Input & Validasi Nilai Kuis: Membaca nilai kuis dengan validasi rentang 0 s.d. 100.
  6. Input & Validasi Nilai UTS: Membaca nilai UTS dengan validasi rentang 0 s.d. 100.
  7. Input & Validasi Nilai UAS: Membaca nilai UAS dengan validasi rentang 0 s.d. 100.
  8. Input & Validasi Kehadiran: Membaca persentase kehadiran dengan validasi rentang 0 s.d. 100%.
  9. Perhitungan Nilai Akhir:
    • Hitung kontribusi tugas = nilaiTugas × 0.20
    • Hitung kontribusi kuis = nilaiKuis × 0.15
    • Hitung kontribusi UTS = nilaiUTS × 0.30
    • Hitung kontribusi UAS = nilaiUAS × 0.35
    • Hitung nilai akhir = jumlah keempat kontribusi di atas.
  10. Penentuan Kategori Nilai:
    • Jika nilaiAkhir ≥ 85.0 maka kategori = "A".
    • Jika nilaiAkhir ≥ 80.0 maka kategori = "B+".
    • Jika nilaiAkhir ≥ 75.0 maka kategori = "B".
    • Jika nilaiAkhir ≥ 70.0 maka kategori = "C+".
    • Jika nilaiAkhir ≥ 60.0 maka kategori = "C".
    • Jika nilaiAkhir ≥ 50.0 maka kategori = "D".
    • Selainnya (nilai < 50.0), maka kategori = "E".
  11. Evaluasi Kelulusan:
    • Jika (nilaiAkhir ≥ 60.0) DAN (nilaiUAS ≥ 50.0) DAN (persentaseKehadiran ≥ 75.0) maka status = "LULUS".
    • Jika salah satu syarat atau lebih tidak terpenuhi, maka status = "TIDAK LULUS", lalu sertakan catatan syarat mana yang belum tercapai.
  12. Tampilkan Rincian Hasil: Mencetak laporan individual yang memuat seluruh identitas, rincian bobot per komponen, nilai akhir, kategori, dan status kelulusan.
  13. Konfirmasi Pengulangan: Meminta konfirmasi apakah pengguna ingin menginput data mahasiswa lain ('y'/'t'). Jika 'y', ulangi langkah 3. Jika 't', lanjutkan.
  14. Selesai: Menampilkan pesan terima kasih dan program berakhir dengan sukses.

ALGORITMA PengolahanNilaiMahasiswa_ModulA
DEKLARASI:
    namaMahasiswa, nimMahasiswa : STRING
    nilaiTugas, nilaiKuis, nilaiUTS, nilaiUAS : REAL
    persentaseKehadiran : REAL
    kontribusiTugas, kontribusiKuis, kontribusiUTS, kontribusiUAS : REAL
    nilaiAkhir : REAL

DESKRIPSI:
    OUTPUT("=== SISTEM PENGOLAHAN NILAI MATA KULIAH - MODUL A ===")
    
    REPEAT
        OUTPUT("Masukkan Nama Mahasiswa : ")
        INPUT(namaMahasiswa)
        OUTPUT("Masukkan NIM Mahasiswa : ")
        INPUT(nimMahasiswa)

        // Validasi Nilai Tugas (0 - 100)
        REPEAT
            OUTPUT("Masukkan Nilai Tugas (0 - 100): ")
            INPUT(nilaiTugas)
            IF (nilaiTugas < 0 OR nilaiTugas > 100) THEN
                OUTPUT("[ERROR] Nilai Tugas harus di antara 0 sampai 100!")
            ENDIF
        UNTIL (nilaiTugas >= 0 AND nilaiTugas <= 100)

        // Validasi Nilai Kuis (0 - 100)
        REPEAT
            OUTPUT("Masukkan Nilai Kuis (0 - 100): ")
            INPUT(nilaiKuis)
            IF (nilaiKuis < 0 OR nilaiKuis > 100) THEN
                OUTPUT("[ERROR] Nilai Kuis harus di antara 0 sampai 100!")
            ENDIF
        UNTIL (nilaiKuis >= 0 AND nilaiKuis <= 100)

        // Validasi Nilai UTS (0 - 100)
        REPEAT
            OUTPUT("Masukkan Nilai UTS (0 - 100): ")
            INPUT(nilaiUTS)
            IF (nilaiUTS < 0 OR nilaiUTS > 100) THEN
                OUTPUT("[ERROR] Nilai UTS harus di antara 0 sampai 100!")
            ENDIF
        UNTIL (nilaiUTS >= 0 AND nilaiUTS <= 100)

        // Validasi Nilai UAS (0 - 100)
        REPEAT
            OUTPUT("Masukkan Nilai UAS (0 - 100): ")
            INPUT(nilaiUAS)
            IF (nilaiUAS < 0 OR nilaiUAS > 100) THEN
                OUTPUT("[ERROR] Nilai UAS harus di antara 0 sampai 100!")
            ENDIF
        UNTIL (nilaiUAS >= 0 AND nilaiUAS <= 100)

        // Validasi Kehadiran (0 - 100%)
        REPEAT
            OUTPUT("Masukkan Kehadiran (%) (0 - 100): ")
            INPUT(persentaseKehadiran)
            IF (persentaseKehadiran < 0 OR persentaseKehadiran > 100) THEN
                OUTPUT("[ERROR] Kehadiran harus di antara 0 sampai 100%!")
            ENDIF
        UNTIL (persentaseKehadiran >= 0 AND persentaseKehadiran <= 100)

        // Perhitungan Komponen Berbobot
        kontribusiTugas  <- nilaiTugas * 0.20
        kontribusiKuis   <- nilaiKuis * 0.15
        kontribusiUTS    <- nilaiUTS * 0.30
        kontribusiUAS    <- nilaiUAS * 0.35
        nilaiAkhir       <- kontribusiTugas + kontribusiKuis + kontribusiUTS + kontribusiUAS

        // Penentuan Kategori Huruf
        IF (nilaiAkhir >= 85.0) THEN
            kategoriNilai <- "A"
        ELSE IF (nilaiAkhir >= 80.0) THEN
            kategoriNilai <- "B+"
        ELSE IF (nilaiAkhir >= 75.0) THEN
            kategoriNilai <- "B"
        ELSE IF (nilaiAkhir >= 70.0) THEN
            kategoriNilai <- "C+"
        ELSE IF (nilaiAkhir >= 60.0) THEN
            kategoriNilai <- "C"
        ELSE IF (nilaiAkhir >= 50.0) THEN
            kategoriNilai <- "D"
        ELSE
            kategoriNilai <- "E"
        ENDIF

        // Evaluasi Syarat Kelulusan
        catatanKelulusan <- ""
        IF (nilaiAkhir >= 60.0 AND nilaiUAS >= 50.0 AND persentaseKehadiran >= 75.0) THEN
            statusKelulusan <- "LULUS"
            catatanKelulusan <- "Memenuhi seluruh persyaratan kelulusan."
        ELSE
            statusKelulusan <- "TIDAK LULUS"
            IF (nilaiAkhir < 60.0) THEN
                catatanKelulusan <- catatanKelulusan + "[Nilai Akhir < 60] "
            ENDIF
            IF (nilaiUAS < 50.0) THEN
                catatanKelulusan <- catatanKelulusan + "[Nilai UAS < 50] "
            ENDIF
            IF (persentaseKehadiran < 75.0) THEN
                catatanKelulusan <- catatanKelulusan + "[Kehadiran < 75%] "
            ENDIF
        ENDIF

        // Menampilkan Output Rincian
        OUTPUT("=== RINCIAN HASIL PENILAIAN INDIVIDUAL ===")
        OUTPUT("Nama Mahasiswa : ", namaMahasiswa)
        OUTPUT("NIM            : ", nimMahasiswa)
        OUTPUT("Nilai Tugas    : ", nilaiTugas, " (Bobot 20% -> Kontribusi: ", kontribusiTugas, ")")
        OUTPUT("Nilai Kuis     : ", nilaiKuis, " (Bobot 15% -> Kontribusi: ", kontribusiKuis, ")")
        OUTPUT("Nilai UTS      : ", nilaiUTS, " (Bobot 30% -> Kontribusi: ", kontribusiUTS, ")")
        OUTPUT("Nilai UAS      : ", nilaiUAS, " (Bobot 35% -> Kontribusi: ", kontribusiUAS, ")")
        OUTPUT("Kehadiran      : ", persentaseKehadiran, " %")
        OUTPUT("Nilai Akhir    : ", nilaiAkhir)
        OUTPUT("Kategori Nilai : ", kategoriNilai)
        OUTPUT("Status Hasil   : ", statusKelulusan)
        OUTPUT("Keterangan     : ", catatanKelulusan)

        // Konfirmasi Pengulangan
        REPEAT
            OUTPUT("Apakah ingin memproses mahasiswa lain? (y/t): ")
            INPUT(pilihanUlang)
        UNTIL (pilihanUlang = 'y' OR pilihanUlang = 'Y' OR pilihanUlang = 't' OR pilihanUlang = 'T')

    UNTIL (pilihanUlang = 't' OR pilihanUlang = 'T')

    OUTPUT("=== PROGRAM SELESAI ===")

        cout << "========================================================\n\n";

        // Konfirmasi Pengulangan
        do {
            cout << "Apakah Anda ingin memasukkan data mahasiswa lain? (y/t): ";
            cin >> pilihanUlang;
            if (pilihanUlang != 'y' && pilihanUlang != 'Y' && pilihanUlang != 't' && pilihanUlang != 'T') {
                cout << "[ERROR] Pilihan tidak valid! Masukkan 'y' atau 't'.\n";
            }
        } while (pilihanUlang != 'y' && pilihanUlang != 'Y' && pilihanUlang != 't' && pilihanUlang != 'T');

        cout << "\n";

    } while (pilihanUlang == 'y' || pilihanUlang == 'Y');

    cout << "========================================================\n";
    cout << "    PROGRAM SELESAI. TERIMA KASIH TELAH MENGGUNAKAN.    \n";
    cout << "========================================================\n";

    return 0;
}
Penjelasan Arsitektur Kode:
  • Sanitasi Buffer Input: Menggunakan getline(cin >> ws, namaMahasiswa) agar pembacaan nama lengkap ber-spasi berjalan bersih tanpa gangguan sisa karakter enter / newline dari input sebelumnya.
  • Penanganan Input Non-Numerik (Anti-Crash): Blok if (!(cin >> nilai)) digunakan untuk mendeteksi apabila pengguna sengaja atau tidak sengaja memasukkan huruf/karakter saat diminta nilai angka. Fungsi cin.clear() dan cin.ignore() membersihkan stream sehingga program tidak mengalami infinite loop atau crash tak wajar (memenuhi Batasan E.8).
  • Penerapan Format Output: Menggunakan pustaka <iomanip> dengan fungsi fixed dan setprecision(2) untuk memastikan angka desimal ditampilkan seragam dengan 2 angka di belakang koma.
  • Keterangan Diagnostik: Saat mahasiswa dinyatakan tidak lulus, program tidak hanya mencetak status "TIDAK LULUS", melainkan secara transparan menyebutkan persis parameter mana yang gagal (misal: [Nilai UAS < 50] atau [Kehadiran < 75%]).
