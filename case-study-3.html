Studi Kasus 03: Sistem Pengolahan Nilai Mata Kuliah (C++)

Semester Ganjil 2026  •  Mahasiswa Sistem Informasi  •  SSI1144 Algoritma
Dokumentasi resmi lengkap proyek UTS ini terbagi menjadi modul-modul terstruktur. Anda dapat langsung membuka:
Analisis Masalah Modul A Modul B Program Terintegrasi Refleksi & AI

1. Deskripsi Permasalahan

Dosen membutuhkan program untuk menghitung nilai akhir mahasiswa berdasarkan proporsi bobot tertentu dan membuat rekapitulasi hasil pembelajaran kelas.

2. Ketentuan Penilaian & Kelulusan

  • Komposisi Bobot: Tugas (20%), Kuis (15%), UTS (30%), UAS (35%).
  • Skala Kategori Nilai:
    • A: 85.00 - 100.00
    • B+: 80.00 - 84.99
    • B: 75.00 - 79.99
    • C+: 70.00 - 74.99
    • C: 60.00 - 69.99
    • D: 50.00 - 59.99
    • E: < 50.00
  • Syarat Kelulusan Simultan: Mahasiswa dinyatakan LULUS jika memenuhi ketiga syarat: Nilai Akhir ≥ 60, Nilai UAS ≥ 50, dan Kehadiran ≥ 75%.

3. Program Terintegrasi (C++)

Program mengolah masukan mahasiswa secara berulang menggunakan konsep akumulator tanpa struktur data array, sesuai batasan proyek:

// Cuplikan Logika Inti Studi Kasus 03 (C++)
kontribusiTugas = nilaiTugas * 0.20;
kontribusiKuis  = nilaiKuis * 0.15;
kontribusiUTS   = nilaiUTS * 0.30;
kontribusiUAS   = nilaiUAS * 0.35;
nilaiAkhir      = kontribusiTugas + kontribusiKuis + kontribusiUTS + kontribusiUAS;

// Evaluasi Kelulusan
if (nilaiAkhir >= 60.0 && nilaiUAS >= 50.0 && persentaseKehadiran >= 75.0) {
    statusKelulusan = "LULUS";
} else {
    statusKelulusan = "TIDAK LULUS";
}

// Akumulasi Modul B (Rekapitulasi Tanpa Array)
totalNilaiAkhir += nilaiAkhir;
if (totalMahasiswa == 1) {
    nilaiTertinggi = nilaiAkhir;
    nilaiTerendah = nilaiAkhir;
} else {
    if (nilaiAkhir > nilaiTertinggi) nilaiTertinggi = nilaiAkhir;
    if (nilaiAkhir < nilaiTerendah)  nilaiTerendah = nilaiAkhir;
}

4. Rekapitulasi Kelas (Modul B)

Setelah seluruh data selesai diinput, sistem menghasilkan statistik kelas lengkap:

  • Jumlah mahasiswa yang lulus dan tidak lulus.
  • Sebaran frekuensi mahasiswa pada kategori A hingga E.
  • Nilai rata-rata kelas, nilai tertinggi, dan nilai terendah.
  • Persentase rasio kelulusan kelas.
